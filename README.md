# SEJUSP-MS_ViolenceAgainstWomen
📊 Dados de Crimes Violentos Letais Intencionais (CVLI) - Mato Grosso do Sul
https://www.dados.ms.gov.br/dataset/crimes-violentos-letais-intencionais-sejusp/resource/crimes-violentos-letais-intencionais-sejusp

🚨 Dataset oficial da Secretaria de Estado de Justiça e Segurança Pública de Mato Grosso do Sul (SEJUP-MS)

📋 Sobre o Dataset
Este conjunto de dados contém o registro detalhado de ocorrências de Crimes Violentos Letais Intencionais (CVLI) e outros crimes correlacionados no estado de Mato Grosso do Sul.

🎯 O que são CVLI?
Crimes Violentos Letais Intencionais são aqueles onde há a intenção de matar, incluindo:

🔪 Homicídio Doloso (simples e qualificado)

👩 Feminicídio

💰 Latrocínio (roubo seguido de morte)

🩸 Lesão Corporal Seguida de Morte

📁 Estrutura do Arquivo
Coluna	Descrição
_id	Identificador único da linha
Nº/ANO	Número do Boletim de Ocorrência e delegacia responsável
FATO	Descrição completa do(s) crime(s) conforme Código Penal
FATO AGRUPADO	Categorização para análise estatística
DATA DO FATO	Data da ocorrência (DD/MM/AAAA)
HORA DO FATO	Horário da ocorrência (HH:MM:SS)
UF	Unidade da Federação (MS)
MUNICÍPIO	Município onde ocorreu o fato
CÓDIGO IBGE	Código IBGE do município (7 dígitos)
BAIRRO	Bairro ou localidade da ocorrência
📈 Estatísticas Rápidas
Indicador	Valor
🗓️ Período	2016 – 2026
📍 Municípios	79
🏙️ Principal município	Campo Grande
🏷️ Principais tipos	Homicídio Doloso, Feminicídio, Latrocínio
🔍 Possíveis Aplicações
Este dataset pode ser utilizado para:

📊 Análise de Segurança Pública – mapeamento da violência letal por região e período

🧠 Estudos Criminais – identificação de padrões e tipologias criminais

📰 Jornalismo de Dados – reportagens investigativas sobre violência no estado

🏛️ Políticas Públicas – subsídio para estratégias de prevenção criminal

🎓 Pesquisa Acadêmica – estudos em sociologia, direito e ciências políticas

⚠️ Observações Importantes
⚠️ Dados sensíveis: Este arquivo contém informações sobre crimes violentos. Utilize com responsabilidade, respeitando vítimas e familiares.

🔄 Natureza investigativa: As tipificações criminais são as registradas no Boletim de Ocorrência e podem ser alteradas ao longo da investigação ou processo judicial.

🏷️ Filtro recomendado: Para análises estritamente de CVLI, filtre os registros que contenham a string CRIMES VIOLENTOS LETAIS INTENCIONAIS na coluna FATO AGRUPADO.
